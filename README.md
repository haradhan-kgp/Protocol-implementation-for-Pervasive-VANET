# Quantum-Safe PUF-Based Authentication for VANETs

C prototype for the paper *"On the Development of Quantum-Safe PUF-Based Authentication for Pervasive Vehicular Networks"*.

Protocol: OBU-RSU mutual authentication and key agreement using Kyber KEM, a PUF with fuzzy extractor, and MAC/AEAD/KDF.
